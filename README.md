# Калькулятор отряда Z Route

Одностраничный русскоязычный калькулятор пятёрки из героев UR и SSR: два слота фронта и три слота тыла, готовые составы, бонусы фракции, уровни, звёзды, обычное снаряжение и автоподбор из имеющихся героев для PvP/PvE. Включены 16 UR (с повышенной Арией) и 12 уникальных SSR; повторная запись Норы из справочника не дублируется.

## Запуск

Откройте `index.html` в браузере или запустите любой статический сервер в этой папке. Сборка и внешние зависимости не требуются. Шрифты включены в проект, а service worker позволяет повторно открыть калькулятор без сети после первого посещения через HTTP(S).

## Данные и ограничения

- По умолчанию: 150 уровень, 5★ и максимальное обычное UR-снаряжение.
- Автоподбор использует только героев с отметкой «Есть» в разделе «Мои герои».
- PvP-рейтинг — явно обозначенная эвристика урона и стойкости фронта, а не официальная игровая мощь.
- Для 15 UR используются опубликованные фан-оценки DPS. Для повышенной Арии UR и всех SSR DPS рассчитывается по коэффициентам автоатаки, боевого навыка и пассива; это модельная оценка, а не замер боя.
- У SSR используется собственная кривая уровней и бонус специальности +10%; у UR — +20%.
- PvE использует оценку урона по зомби, включая отдельную оценку Витторе против гигантского захватчика, бонус SSR-снаряжения и фактические бонусы «урон монстрам» в навыках. Усиление Ким Мины усредняется по перезарядке.
- SSR- и UR-версии Арии считаются одним героем и не могут одновременно входить в отряд.
- Ресурсы прокачки, эксклюзивное оружие и аккаунтные бонусы не учитываются.
- Точный бой, сопротивления, контроль и снижение защиты Кати не моделируются.
- Настройки хранятся в `localStorage` только текущего браузера. Они не синхронизируются и удаляются при очистке данных браузера.

Проект работает локально в браузере и не обращается к игровому аккаунту.
